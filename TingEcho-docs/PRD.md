# TingEcho 产品需求方案

状态：待评审。基线提交：3beee525332747a2c6ad163abcfbc12b6fb94b92。首位用户在安卓上随身记录，在 Windows 上整理回看；iOS 同属正式支持平台。本文取代 项目根目录旧需求草案中的中文单语言和目录规划。

## 一、项目目标与非目标

**她能随手留下今天的一件事，过几天围绕同一件事接着记，回头看见自己的变化。** 例如第一次练跳投，她只拍了十秒视频。三周后她想知道自己的动作变了多少，打开「学会跳投」就能依次看两次练习，再写下「现在出手稳多了」。两次记录之间隔多久，都不影响这个体验。

首版交付三个动作：随手记、按成长主题接着记、挑两次经历看变化。允许先记后整理，一条记录可进入多个主题。私密、本地优先、无社交、无广告。工作、存钱、阅读和兴趣提供可选命名示例，她也可以写「做出妈妈喜欢的菜」。主题只需名字，不要求掌握度、目标金额或每日填写。

**MVP 边界。** 本期不建四套垂直子系统，不做理财账本、强制连续打卡、能力评分、公众号抓取或全新 AI 平台。周期复盘、文章来信及目标统计保留为后续需求。已有的模型配置、推送和同步能力继续可用。全局品牌更名属于首版交付；三个平台、八份现有语言资源及语言切换完整继承。

## 二、用户操作流程

1. **打开就记。** 首屏突出「记一下」。直接写一句、选择媒体或进入完整编辑器；首次使用可跳过建主题和联网配置。人在球场时拍视频，想练英语时可留下原声。只有使用相应能力时才请求权限。
2. **保存到自己的主题。** 保存时可选已有主题，也可输入新名字。跳过后，记录立即出现在最近记录中，之后随时补选。原版普通标签可直接打开；系统标签不出现在成长主题选择器。
3. **接着上次记。** 从首页最近主题进入，看到上一次的日期、内容及媒体，点「接着记」即预选该主题。放弃编辑或保存失败不产生重复记录。
4. **看看变化。** 主题有两条可见记录时，默认取最早和最近两条，允许重选。手机上下排列，Windows 宽窗并排；点击播放其中一段会暂停另一段。只有一条时显示该条与「接着记」。点任何一张可回原文；可选感想保存为同主题的新记录。
5. **换设备继续。** 在设置选带媒体的完整备份，在另一设备恢复。恢复结果中可重新打开对应主题、历史地点天气和原始附件。日常同步沿用现有入口。

## 三、功能清单及优先级

P0 为首个可交付版本的主流程及兼容性要求，P1 为她开始使用后的增强，P2 根据真实记录习惯决定投入。

| 类别 | 优先级 | 功能与交付内容 |
| --- | --- | --- |
| 保留的原功能 | P0 | 富文本、草稿、图片、音频、视频、拍摄、标签、搜索、时间排序、收藏、回收站、地图、定位天气、隐藏笔记与生物识别。保留原有权限及设备能力判断。 |
| 保留的原功能 | P0 | 本地保存、备份恢复、局域网/WebDAV 同步、三端架构、全部现有语言、主题外观、模型配置、助手和推送设置继续可达。 |
| 需修改/重写UI的功能 | P0 | 首页按「记一下 → 最近主题 → 最近记录」排列。空首页仅给一个记录入口和一句邀请。次要工具放入可发现的更多或设置入口。复用现有纸张风格和主题令牌，随亮暗模式变化，以留白、日期和真实内容形成层次。 |
| 需修改/重写UI的功能 | P0 | 将普通标签的浏览组织成成长主题页，最近一次记录优先显示。编辑器只增主题预选和补选路径。主题改名后关联仍有效。 |
| 需修改/重写UI的功能 | P0 | 全局更名覆盖界面文案、应用图标相关品牌资源、安装展示名、Dart 包和引用、三端安装标识、后台任务、服务发现、同步标识、构建脚本与产物。独立安装后两款应用的数据各自归属。 |
| 全新增加的功能 | P0 | 同主题「看看变化」视图及选两条记录的交互。使用原记录、原附件和原播放器。安卓原声直录如果经实测有缺口，只补录制并交给现有附件流程。 |
| 全新增加的功能 | P1 | 轻复盘。按周/月/季选择时间段，挑出有意义的记录，写一句变化及下一步；可选标记硬实力或软实力。可查看关联原文。 |
| 全新增加的功能 | P1 | 「来信」展示自己的旧记录、按主动选择的兴趣生成的短句、或精选文章链接。复用现有推送调度；可调频率、关闭、收藏或减少该类内容。通知预览隐藏私人内容，文章卡标明来源。 |
| 全新增加的功能 | P1 | 成长助手复用模型 ID、Base URL、密钥管理与现有工具，按适配能力明确标示 API 格式。优先回答「最近练习有什么变化」，可回原文，写入前展示提案并确认。 |

## 四、验收标准（DoD）

以下为交付条件。当前阶段证据来自静态源码，运行结果在开发阶段记录。

| 场景 | 通过条件 |
| --- | --- |
| 首次使用与离线 | 全新安装、断网、跳过主题和 AI 配置，可从首页保存文字并在重启后找到。无需账号或连续打卡。她无需讲解能独立完成记录、接着记、回看三项操作。 |
| 媒体与草稿 | 安卓拍照、录一段原声、拍一段视频，分别保存并在重启后查看或播放；验证仅含附件的记录。编辑中退出能按既有草稿规则找回，取消和失败重试均不出现重复条目。拒绝相机或麦克风权限后仍可写字和选已有文件。 |
| 主题与回顾 | 零条、一条、两条以上均有相应界面。选两条、切换媒体、打开原文、保存感想都可完成；未归类记录、多主题记录、旧标签改名均可正确浏览。同一记录只保存一份。 |
| 地点与天气 | 开启后可保存当时的位置和天气；拒绝授权或天气超时仍能保存正文与附件。回看保留历史值。 |
| 隐私与删除 | 隐藏、删除或恢复一条记录后，主题计数、列表、对照页及候选内容及时反映可见性。锁屏通知及 AI 工具不能泄露隐藏内容。 |
| 备份、同步与兼容 | 安卓导出含图、音、视频的 ZIP，在干净 Windows 数据目录恢复并逐项打开；此前版本的 JSON 和 ZIP 仍可导入，重复导入遵循原合并规则。局域网和 WebDAV 至少各验证一次含媒体同步。 |
| 三端、语言与外观 | Android、Windows、iOS 分别完成构建、安装、启动、记录与回看。现有八种语言均可选择并重启保留，新增文案符合仓库本地化回退规则。窄屏、桌面宽窗、亮暗色及大字号下按钮可读可点。 |
| 全局更名 | 扫描版本控制下的自有源码、配置、测试、资源及打包清单，旧品牌命名（含大小写及分隔符变体）残留为零；核验安装、后台任务、服务发现及两台新产品设备同步。发布产物展示 TingEcho，能与原版共存且各自数据可独立恢复。 |
| 交付证据 | 记录构建版本、设备/系统、验证结果及尚存缺陷。P0 路径全部通过后交付试用。 |
